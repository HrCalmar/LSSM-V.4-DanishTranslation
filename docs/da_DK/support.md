# Support 👨‍💻

## Retningslinje

En lille hjælp, der kan guide dig til at oprette en supportanmodning.

:::tip
Hvis du har brug for assistance, beskriv dit problem så præcist som muligt.
Jo bedre og mere detaljeret du beskriver dit problem, desto hurtigere og bedre kan vi hjælpe dig.
:::
:::warning
Bemærk venligst, at vi ikke officielt understøtter ældre browsere, mobile browsere samt Microsoft Edge eller Internet Explorer.
Support for disse browsere er derfor hverken garanteret eller sandsynlig.
:::

### 1. Formuler problemet

Beskriv først dit problem. Inkluder alle oplysninger, der kunne være vigtige. Forklar også, hvad du allerede har forsøgt.

### 2. Angiv brugerdata

Angiv venligst dit brugernavn eller bruger-ID. Det er også nyttigt at nævne de aktiverede moduler.

### 3. Rapportér problemet

Nu kan du sende os dit formulerede problem med brugerdata. Brug en af de muligheder, der er angivet nedenfor.

## Via Discord

På vores <discord/> kan du få support i kanalen <discord-channel channel="lssm-help"/>.

## På GitHub

Du kan også oprette en issue på [GitHub][github.issues].
Tjek venligst, om en issue for dette problem allerede eksisterer, og følg den op der.

## Planlagt: Support direkte i spillet

For at kunne give dig support endnu hurtigere og nemmere, ønsker vi at integrere vores egen supportchat.
Når den bliver tilgængelig, vil du kunne tilgå den via LSSM-menuen i spillet.
Vi vil gøre vores bedste for at hjælpe dig så godt og hurtigt som muligt, men igen: Jo mere detaljeret du beskriver dit problem fra starten, desto bedre kan vi hjælpe dig!

Så snart denne funktion er klar, vil vi naturligvis informere dig om det i release notes. :wink:
